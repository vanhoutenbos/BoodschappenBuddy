# Marktonderzoek – BoodschappenBuddy

Dit document bevat de marktonderzoeksvragen en -bevindingen voor BoodschappenBuddy.

## Doelgroep

Nederlanders die:
- Wekelijks boodschappen doen
- Willen besparen via aanbiedingen
- Inspiratie zoeken voor maaltijden

## Enquête-vragen

1. **Hoe plan je nu je boodschappen?**
   - [ ] Ik maak een lijstje op papier
   - [ ] Ik gebruik een app (welke?)
   - [ ] Ik ga spontaan
   - [ ] Anders

2. **Wat vind je het meeste gedoe aan wekelijkse boodschappen?**
   - [ ] Bedenken wat ik ga koken
   - [ ] Bijhouden wat ik nodig heb
   - [ ] Aanbiedingen zoeken
   - [ ] Naar meerdere supermarkten gaan

3. **Hoeveel supermarkten bezoek je gemiddeld per week?**
   - [ ] 1
   - [ ] 2
   - [ ] 3+

4. **Hoe belangrijk zijn aanbiedingen in je keuze voor producten/supermarkt?**
   - [ ] Heel belangrijk (ik plan mijn maaltijden rondom aanbiedingen)
   - [ ] Enigszins belangrijk
   - [ ] Niet zo belangrijk

5. **Zou je €1–2 per maand willen betalen als je daarmee structureel meer bespaart?**
   - [ ] Ja, zeker
   - [ ] Misschien, afhankelijk van de besparing
   - [ ] Nee

6. **Welke functie vind je het belangrijkst?**
   - [ ] Aanbiedingen vergelijken
   - [ ] Weekmenu's genereren
   - [ ] Automatische boodschappenlijstjes
   - [ ] Recepten ontdekken

### Onderscheidend vermogen BoodschappenBuddy

- Vergelijkt aanbiedingen van **meerdere** supermarkten
- Combineert aanbiedingen met **gepersonaliseerde** weekmenu's
- Intuïtieve **swipe-interface** voor receptontdekking
- Gericht op de **Nederlandse markt**
